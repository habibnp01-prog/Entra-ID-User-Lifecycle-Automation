# Installation Guide

## Entra ID User Lifecycle Automation

This document provides the installation, configuration, testing, and initial deployment procedure for the Entra ID User Lifecycle Automation project.

---

## 1. Prerequisites

Before using the project, verify the following requirements.

### Operating System

Supported platforms:

- Windows 10 or later
- Windows Server 2016 or later

### PowerShell

Windows PowerShell 5.1 or later is required.

Check the installed version:

```powershell
$PSVersionTable.PSVersion
